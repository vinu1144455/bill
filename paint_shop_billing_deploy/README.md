# Paint Shop GST Billing & Inventory Management

A fast, lightweight **Node.js & Express** billing and inventory management application configured for 1-click free deployment on [Vercel](https://vercel.com).

---

## 🚀 Free Deployment on Vercel

### Step 1: Upload / Push to GitHub
1. Upload this project to your repository on **[GitHub](https://github.com)**.

### Step 2: Deploy on Vercel
1. Go to **[Vercel](https://vercel.com)** and sign in.
2. Click **Add New...** > **Project**.
3. Select and import your GitHub repository.
4. **Framework Preset**: Leave as **Other** (or Express/Node.js).
5. **Build and Output Settings**: Leave all switches default / OFF.
6. Click **Deploy**!

Your app will be live with a free `https://*.vercel.app` URL immediately.

---

## 💻 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
